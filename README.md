# icsi418Y - pa4

## Description

In this application, I built on PA3 and added features for creating, viewing, editing, and deleting user stories. I also added project backlogs, story assignments, and validation for removing project members who have assigned stories. I used React, Node.js, Express, and MongoDB.

## Instuction to Run Application

### Backend

1. Open a terminal.
2. Navigate to the server folder and install the dependencies.
3. Start the backend: `node server.js`

The backend runs on port 9000.

### Frontend

1. Open another terminal.
2. Navigate to the client folder and install the dependencies.
3. Start the frontend: `npm run dev`
4. Open the local URL displayed in the terminal, usually `http://localhost:5173/`.

### Test Data

1. Create at least three users and two projects.
2. Add members to the projects.
3. Create at least five user stories across both projects.
4. Include High, Medium, and Low priorities.
5. Include To Do, In Progress, and Done statuses.
6. Include both assigned and unassigned stories.
